One funny line, written by a small Python program for make.fun's "One-Line Laugh-Off" bounty.

## The entry

> My Roomba left me for the vacuum cleaner. Its note said: 'He sucks, but at least he means it.'

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (1–200 characters, UTF-8, single line), and refuses to write anything if the line ever fails that gate.
